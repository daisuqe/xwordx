# XWORDX

クロスワード形式の対戦ワードゲーム (あなた対 COM)。ブラウザで遊ぶ、ビルド不要の静的ファイルです。

A crossword-style, turn-based word battle game (you vs. COM) that runs in the browser as static files.

## 遊ぶ / Run locally

```
python tools/serve.py 8000
```

`http://localhost:8000/` を開きます。
